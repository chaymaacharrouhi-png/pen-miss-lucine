# Miss Lucine — Static Site

This folder contains a static author website ready to deploy to GitHub Pages. Files are under `site/` and assets live in `site/assets`.

Quick deploy:

1. Create a GitHub repository.
2. Copy the contents of `site/` into a `docs/` folder or publish from the repository root.
3. Push the repo to GitHub and enable Pages in repository settings.

Notes:
- Amazon links are updated for published titles; the remaining in-progress books use a coming-soon message.
- The contact form is currently a placeholder and should be connected to your own submission backend.
- A production-ready `sitemap.xml` and `robots.txt` are included.
- Use `book-1.html` through `book-7.html` for individual book pages.
